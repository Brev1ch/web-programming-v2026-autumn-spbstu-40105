# Лабораторная работа 5
 
## Задание
 
Вариант 22, задача 5. Создать игру "Крестики-нолики" — классическую игру
с возможностью игры против компьютера или другого игрока. Обязательны
заставка (занимающая всё рабочее поле) и экраны завершения игры.
Использование готовых игровых библиотек (Phaser и подобных) запрещено.
 
## Реализация
 
Приложение построено на React (Vite). Игровая логика вынесена в отдельный
модуль `gameLogic.js`, не зависящий от React — это чистые функции
(`calculateWinner`, `isBoardFull`, `getRandomComputerMove`,
`createEmptyBoard`), которые легко тестировать отдельно от интерфейса.
 
Компонент `App.jsx` управляет тремя экранами через простой стейт-машину
(`screen`: `splash` / `playing` / `gameOver`):
 
- **`Splash`** — заставка на весь экран с выбором режима (против
  компьютера или против другого игрока за одной клавиатурой).
- **`Board`** — сетка 3×3 из кнопок; клик по пустой клетке ставит символ
  текущего игрока.
- **`GameOverScreen`** — показывается при победе или ничьей, с кнопкой
  "Играть снова" (возвращает на заставку).
Ход компьютера реализован через `useEffect`, который следит за тем, что
сейчас ход `'O'` в режиме `mode === 'computer'`, и через `setTimeout`
(400мс) делает случайный ход среди свободных клеток — небольшая задержка
имитирует "раздумье" и не даёт компьютеру ходить мгновенно и незаметно
для игрока.
 
Проверка победителя (`calculateWinner`) перебирает все 8 возможных
выигрышных линий (3 горизонтали, 3 вертикали, 2 диагонали) и проверяет,
заполнена ли линия одним и тем же символом.
 
Корневой элемент приложения — `<main data-testid="app">`, как того
требует общий контракт лабораторной. Игровое поле помечено
`data-testid="game-board"`, а каждая клетка — `data-testid="game-cell"`
(имена подтверждены сообщением грейдера в CI).
 
Игровых библиотек (Phaser и подобных) не используется — только React
и обычный DOM/CSS для отрисовки.
