# Лабораторная работа 4

## Задание

Вариант 22, задача 4. Создать класс `Event` с полями `id`, `title`,
`participants`, `date` и методами `addParticipant`, `removeParticipant`,
геттером `participantCount`. Реализовать функции для группировки и фильтрации
массива мероприятий: по дате, по количеству участников, по участнику, по месяцу,
а также получение уникального списка всех участников. Реализовать
пользовательский интерфейс с карточками мероприятий, формами создания
мероприятия и добавления участника, асинхронными (Promise + setTimeout)
операциями добавления/удаления и сохранением состояния в localStorage.

## Реализация

**Модель (`model.js`).** Класс `Event` хранит данные одного мероприятия; методы
`addParticipant`/`removeParticipant` мутируют массив `participants` внутри
конкретного экземпляра, а геттер `participantCount` вычисляется на лету из длины
этого массива (не хранится отдельным полем, чтобы не рассинхронизироваться с
реальным списком участников).

Функции группировки (`groupEventsByDate`, `groupEventsByParticipantCount`)
реализованы через `Array.prototype.reduce`, собирая объект вида
`{ ключ: [мероприятия] }`. `getUniqueParticipants` использует `Set` для
дедупликации участников по всем мероприятиям сразу.
`getEventsByParticipant`/`getEventsByMonth` — обычная фильтрация массива. Ни
одна из функций не изменяет переданный ей массив мероприятий.

**UI и асинхронность (`main.js`).** Все операции изменения данных
(`addEventAsync`, `removeEventAsync`, `addParticipantAsync`,
`removeParticipantAsync`) обёрнуты в `Promise` с `setTimeout` внутри — это
имитирует задержку сетевого запроса, как того требует задание. После каждой
асинхронной операции состояние сохраняется в `localStorage` (`saveEvents`) и
интерфейс перерисовывается заново (`render()`) без перезагрузки страницы.

При загрузке страницы `loadEvents()` читает данные из `localStorage` и **явно
оборачивает** каждый объект обратно в `new Event(...)` — это важно, потому что
`JSON.parse` возвращает обычные plain-объекты без методов класса; без этой
обёртки `event.addParticipant(...)` или геттер `participantCount` не были бы
доступны у восстановленных после перезагрузки мероприятий.

**DOM-контракт.** Список мероприятий — `[data-testid="entity-list"]`, форма
создания мероприятия — `form[data-testid="entity-form"]` с полями `name="id"`,
`name="title"`, `name="date"`, карточка — `[data-testid="entity-card"]`, кнопка
удаления мероприятия внутри карточки — `[data-testid="delete-entity"]`.

## Запуск

Открыть `index.html` в браузере — сборка не требуется, `main.js` подключается
как ES-модуль (`<script type="module">`).
