# Лабораторная работа 2

## Задание

Вариант 22, задача 2. Реализовать функцию, которая кодирует строку с
использованием алгоритма RLE (Run-Length Encoding): `"AAABBBCC" -> "3A3B2C"`.

## Реализация

Функция `rleEncode` проходит по строке один раз слева направо и считает длину
текущей последовательности одинаковых символов подряд. Как только встречается
символ, отличный от текущего, накопленная пара "количество + символ"
дописывается в результат, а счётчик сбрасывается на новый символ. После
окончания цикла последняя накопленная последовательность дописывается отдельно,
так как для неё не происходит "смены символа", которая обычно триггерит запись в
результат.

Имя экспорта `rleEncode` — рабочее (контракт с точным именем экспорта для своего
варианта пока не был предоставлен), при необходимости легко переименовать без
изменения логики.

Граничные случаи:

- пустая строка возвращает пустую строку;
- одиночный символ без повторов кодируется как `"1<символ>"` (например,
  `"A" -> "1A"`, `"ABC" -> "1A1B1C"`);
- функция работает с любыми символами (не только буквами), так как сравнение
  идёт посимвольно без привязки к алфавиту;
- исходная строка не изменяется — функция только читает `input` и строит новую
  строку `result`.

## Запуск

Импортировать функцию как ES-модуль и вызвать напрямую:

```js
import {rleEncode} from './solution.js';

console.log(rleEncode('AAABBBCC')); // "3A3B2C"
```

Файл не требует сборки — достаточно среды с поддержкой ES-модулей (например,
Node.js с `"type": "module"` или запуск в браузере через
`<script type="module">`).
